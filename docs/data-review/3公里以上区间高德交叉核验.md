# 3 公里以上区间：高德交叉核验

核对日期：2026-11-05。本记录是当时的历史快照，不包含 2026-11-12 开通的重庆 15 号线。对照 [高德地图](https://www.amap.com/) 的地铁线路站序与站点位置。

## 范围与结论

- 遍历 17 个城市，筛选视图站点的直线距离不少于 3 公里，或 OSM 候选折线长度不少于 3 公里的区间。缺少可靠折线且直线不足 3 公里的长绕行区间不在本次范围。
- 共 384 条城市线路区间，均与高德对应线路的相邻站序一致。南京 S3 线的刘村站采用名称归一处理。
- 285 条显示 OSM 候选走向，99 条显示直线估算。高德线网示意坐标不代表实际地理轨迹；站序一致不能证明每处拐弯已得到核实。
- 南京 6 号线 20 个手工站点坐标已是 WGS84，之前重复反算导致地图位置偏移约 500 米。现已在生成视图数据时针对这些已知原始坐标跳过重复反算。原站点数据与路径计算没有在本次改写。
- 修复后，长区间端点与高德站位经近似坐标转换比较，没有发现超过 200 米的偏差。该数值用于定位显著异常，不代表绝对位置精度。
