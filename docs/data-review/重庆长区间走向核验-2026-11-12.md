# 重庆超过 3 公里区间走向核验

日期：2026-11-12。以当前重庆地理站点坐标的站间直线距离超过 3 公里为筛选条件；同时检查已有 OSM 折线长度超过 3 公里但站间直线不超过 3 公里的区间，本次没有额外区间。候选距离是几何估算，不是运营里程。没有可靠曲线数据的区间即使实际里程超过 3 公里、直线却未达到 3 公里，也无法仅据此筛出。

筛出 22 段：16 段已有 OSM 折线，核对已有站点端点吻合情况和线段长度，未变更；6 段为直线估算。本次将其中 5 段更新为 OSM 走向，另 1 段保留直线估算。此前记录 15 号线的短区间试验不在本次大于 3 公里的范围内。

## 使用与复现

覆盖数据为 `data/geometry/chongqing-long-segments.json`。构建脚本会检查已核查站点坐标是否与记录一致，若站点变化或自动匹配结果发生变化，将停止并要求重新核对；随后将人工核对的区间应用至重庆地理数据。线路拓扑、站点坐标、最短线路和城市线网之最预计算不变；方向玫瑰图会根据新几何数据重新计算，仍包含其他估算区间。
