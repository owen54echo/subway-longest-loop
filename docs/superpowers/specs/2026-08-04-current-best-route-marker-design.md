# 当前最佳路线标记设计

## 目标

当用户在精确计算尚未完成时采用当前最佳路线，保留其可用性，同时清楚但克制地提示该状态。移除“近似”文字及手写体边框标记。

## 选定方案

采用 A 方案：小型虚线圆环。

- 路书标题右侧显示 17px 虚线圆环，中心为现有绿色强调点。
- 网页中圆环缓慢旋转，表示计算过程未完成；遵循 `prefers-reduced-motion` 时停止动画。
- 分享图片、打印页和完整导出中使用同一轮廓的静态圆环，不显示动画或“近似”文字。
- `title`、`aria-label` 和导出页的可访问说明统一为“当前最佳路线，计算未完成”。

## 范围

- 仅在 `isApproximate` 为真时展示圆环。
- 完成精确计算得到的路线不展示任何状态标记。
- 不改变计算、停止、采用当前最佳路线或路线分享的业务逻辑。

## 验收

1. 路书和三类分享输出中不再出现“近似”文字。
2. 当前最佳路线显示圆环；精确路线不显示。
3. 小屏幕下圆环不挤压标题或分享卡内容。
4. 无障碍名称说明路线为计算未完成时的当前最佳路线。
